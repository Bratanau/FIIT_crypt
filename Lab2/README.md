# Lab2 — теория чисел, тесты простоты и RSA

Это лабораторная работа по криптографии и математике чисел. В проекте реализованы фундаментальные алгоритмы, которые лежат в основе современных криптосистем: вычисление НОД, расширенный алгоритм Евклида, символы Лежандра и Якоби, функции Эйлера и Кармайкла, тесты простоты и схема RSA.

Реализация на Go использует только стандартную библиотеку `math/big` для арифметики больших целых чисел и `crypto/rand` для безопасного случайного выбора. Здесь не используется готовый «магический» криптографический API для простоты, RSA или проверки простоты — всё реализовано вручную на основе математических принципов.

## Что в проекте

  - расширенный алгоритм Евклида / коэффициенты Безу

  - тест Ферма
  - тест Солова–Штрассена

  - отдельная генерация ключей, уязвимых к атаке Винера

## Основные криптографические идеи

### 1. Арифметика по модулю

Криптография работает не с обычной арифметикой, а с арифметикой по модулю `m`.

Запись:

- `a ≡ b (mod m)` означает, что `a` и `b` дают одинаковый остаток при делении на `m`.

Примеры:

- `17 ≡ 2 (mod 5)`
- `9 ≡ 1 (mod 8)`

Это позволяет строить системы, в которых операции выполняются в «кольце остатков»:

- сложение: `(a + b) mod m`
- умножение: `(a * b) mod m`
- возведение в степень: `a^k mod m`

Такая арифметика используется в RSA, в проверках простоты и в многословных схемах цифровой подписи и обмена.

### 2. НОД и обратимость

Наибольший общий делитель (НОД) двух чисел `a` и `b` — это наибольшее число, на которое оба делятся без остатка.

Пример:

- `gcd(48, 18) = 6`

Если `gcd(a, m) = 1`, то число `a` обратимо по модулю `m`. Это значит, что существует `a^{-1}` такое, что:

```text
a * a^{-1} ≡ 1 (mod m)
```

Например, `3^{-1} mod 11 = 4`, потому что `3 * 4 = 12 ≡ 1 (mod 11)`.

Обратимость критична для RSA: закрытый показатель `d` является обратным к открытому показателю `e` по модулю `φ(n)`.

### 3. Расширенный алгоритм Евклида и коэффициенты Безу

Обычный алгоритм Евклида вычисляет НОД. Расширенный алгоритм Евклида находит коэффициенты `x` и `y`, такие что:

```text
ax + by = gcd(a, b)
```

Это даёт возможность находить обратное число по модулю:

```text
a * x ≡ 1 (mod m)
```

когда `gcd(a, m) = 1`.

### 4. Простые числа

Простое число — это целое число `p > 1`, которое делится только на `1` и на себя.

Примеры простых чисел: `2, 3, 5, 7, 11, 13...`

Для криптографии простые числа важны, потому что:

- произведение двух больших простых чисел используется в RSA;
- генерация больших простых чисел — основа надежного шифрования;
- проверка простоты — фундаментальная задача.

### 5. Функция Эйлера φ(n)

Функция Эйлера φ(n) равна количеству чисел от `1` до `n`, взаимно простых с `n`.

Примеры:

- φ(12) = 4, потому что числа `1, 5, 7, 11` взаимно просты с `12`
- φ(7) = 6

Если `n = p * q` и `p, q` — разные простые числа, то:

```text
φ(n) = (p - 1)(q - 1)
```

Это ключевое утверждение RSA.

### 6. Функция Кармайкла λ(n)

Функция Кармайкла λ(n) — это более точная форма «порядка группы обратимых элементов по модулю n`.

Для RSA она часто используется в теории, но в классической схеме больше известна функция Эйлера φ(n).

Если `n = p*q`, то:

```text
λ(n) = lcm(p - 1, q - 1)
```

Это значение часто меньше φ(n), но в контексте криптографии обе функции важны.

### 7. Символ Лежандра и Якоби

#### Символ Лежандра

Для простого числа `p` символ Лежандра ` (a / p) ` равен:

- `1`, если `a` является квадратичным вычетом по модулю `p`
- `-1`, если не является
- `0`, если `a ≡ 0 (mod p)`

Он тесно связан с критерием Эйлера:

```text
a^((p-1)/2) ≡ (a / p) (mod p)
```

#### Символ Якоби

Для не обязательно простого нечетного числа `n` символ Якоби определен как произведение символов Лежандра по простым делителям `n`.

Он используется в криптографии, особенно в тестах простоты, потому что:

- считается быстрее, чем полный факторный анализ;
- используется в тесте Солова–Штрассена.

### 8. Проверка простоты

Проверка простоты — это не просто деление на все числа до квадратного корня. Для больших чисел это слишком медленно. Поэтому используют вероятностные тесты.

#### Тест Ферма

Проверяет условие:

```text
a^(n-1) ≡ 1 (mod n)
```

для случайных `a`.

Если `n` — простое число, то условие выполняется для всех `a`, взаимно простых с `n`.

Проблема: есть составные числа, называемые числами Кармайкла, которые проходят этот тест для многих `a`. Поэтому тест Ферма не считается строгим и не подходит для производства RSA без дополнительных мер.

#### Тест Солова–Штрассена

Комбинирует символ Якоби и модульное возведение в степень:

```text
a^((n-1)/2) ≡ Jacobi(a, n) (mod n)
```

Для простого `n` это верно; для составного `n` оно выполняется с вероятностью не более `1/2` на случайный `a`.

#### Тест Миллера–Рабина

Самый популярный и практичный тест в криптографии. Его идея основана на записи:

```text
n - 1 = 2^s * d
```

Затем проверяются последовательные квадраты числа `a^d mod n`.

Если хотя бы одно промежуточное значение не равно `1` и не равно `n - 1`, число составное.

Тест Миллера–Рабина очень быстрый и используется в реальных системах генерации больших простых чисел.

### 9. RSA

RSA — это криптосистема с открытым ключом, предложенная Ривестом, Шамиром и Адлеманом.

#### Генерация ключей

1. Выбираются два больших простых числа `p` и `q`
2. Вычисляется:

```text
n = p * q
φ(n) = (p - 1)(q - 1)
```

3. Выбирают открытый показатель `e`, который удовлетворяет:

```text
1 < e < φ(n)
gcd(e, φ(n)) = 1
```

4. Вычисляют закрытый показатель `d` как обратный к `e` по модулю `φ(n)`:

```text
e * d ≡ 1 (mod φ(n))
```

5. Пара `(n, e)` — открытый ключ, `(n, d)` — закрытый ключ.

#### Шифрование

Сообщение `m` шифруется так:

```text
c = m^e mod n
```

#### Расшифрование

```text
m = c^d mod n
```

Поскольку `e * d ≡ 1 (mod φ(n))`, эти вычисления восстанавливают исходное сообщение при корректных условиях.

### 10. Почему RSA работает

Для RSA важно, что:

```text
m^(e*d) ≡ m (mod n)
```

для большинства допустимых сообщений `m` при правильных условиях. Это основано на теореме Эйлера и свойствах функции φ(n).

### 11. Уязвимость к малому `d`: атака Винера

Если закрытый показатель `d` слишком мал, то RSA становится уязвимой.

Идея атаки Винера:

- при небольшом `d` дробь `e / n` можно приблизить подходящими дробями из цепной дроби;
- это позволяет восстановить `d` и затем вычислить φ(n), а значит и простые множители `p`, `q`.

Атака работает, когда:

```text
d < n^(1/4) / 3
```

или близко к этой границе.

В проекте реализована демонстрация такой атаки: алгоритм проверяет подходящие дроби, находящиеся в цепной дроби, и пытается восстановить `d` и `φ(n)`.

### 12. Почему учебный RSA не безопасен в реальности

В этом проекте реализован «текстовый» RSA в учебном виде. Он не использует:

- OAEP / PSS
- случайной разметки сообщения
- проверки подлинности
- защиты от повторного шифрования
- шифрования с минимальной длиной блока

Поэтому этот код подходит только для демонстрации математики и лабораторного понимания, но не для реальной защиты данных.

В реальном мире RSA обычно используется:

- `RSA-OAEP` для шифрования данных
- `RSA-PSS` для цифровых подписей
- `ECDSA`, `Ed25519` и другие современные схемы

### 13. Параметры и ограничения проекта

В реализации предусмотрены ограничения для образовательных целей:

- `EulerPhiByDefinition` и `EulerPhiByDFT` ограничены значением `n <= 1_000_000`
- факторизация выполняется через простое переборное разложение и подходит для учебных примеров, а не для больших RSA-модулей
- тест Ферма не гарантирует полную надежность для всех составных чисел
- тест Миллера–Рабина считается предпочтительным для генерации RSA-простых чисел

## Пример использования

```go
nt := lab2.NumberTheory{}

gcd, _ := nt.GCD(big.NewInt(240), big.NewInt(46))
legendre, _ := nt.LegendreSymbol(big.NewInt(2), big.NewInt(7))
modExp, _ := nt.ModExp(big.NewInt(7), big.NewInt(128), big.NewInt(13))

fmt.Println(gcd)
fmt.Println(legendre)
fmt.Println(modExp)
```

Для проверки простоты:

```go
test, _ := lab2.NewPrimalityTest(lab2.MillerRabin)
prime, _ := test.Test(big.NewInt(97), 0.99)
fmt.Println(prime)
```

Для RSA:

```go
service, _ := lab2.NewRSAService(lab2.MillerRabin, 0.99, 256)
pair, _ := service.GenerateKeyPair()

ciphertext, _ := service.Encrypt([]byte("hello"))
plaintext, _ := service.Decrypt(ciphertext)
```

1. Криптография сильно опирается на теорию чисел.
2. Большие простые числа и функции Эйлера/Кармайкла — база RSA.
